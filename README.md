# Python Exercism

My solutions for the [Exercism Python track](https://exercism.org/tracks/python).

Each exercise lives in its own folder with the solution, tests, and Exercism-provided docs. Some early exercises are grouped under `Intro/`, `Bools/`, `Numbers/`, `Strings/`, and `Comparisons/`; the rest sit at the repo root.

## Running tests

From an exercise folder:

```bash
python -m unittest discover
```

Or with pytest:

```bash
pytest
```

## Note

Exercise descriptions and test suites come from [Exercism](https://exercism.org). See each folder's `README.md` for the problem statement.
